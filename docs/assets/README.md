# Felix OS Assets & Artwork

This directory contains the official mascot icons, logo graphics, and concept artwork for **Felix OS**.

## Official Mascot & Icon Set

* **`felix_mascot.png`** — 1024×1024 high-resolution transparent PNG cutout.
* **`felix_mascot_shadow.png`** — 1024×1024 transparent PNG with soft ground contact shadow (ideal for web and document headers).
* **`felix_mascot_white.jpg`** — Original 1024×1024 source graphic on solid white.
* **`felix_icon.ico`** — Multi-resolution Windows icon file containing 16×16, 24×24, 32×32, 48×48, 64×64, 128×128, and 256×256 icon layers.
* **`felix_icon_{16,32,64,128,256,512}.png`** — Individual pre-scaled PNG icons for application icons, favicons, and repository badges.

## Concept Artwork & Character References

* **`Felix_mascot_toys.jpg`** — Full illustration featuring Felix surrounded by software standard and POSIX cat toys.
* **`Felix_cleaning_front.jpg`** — Original front-facing mid-grooming character design.
* **`Felix_cleaning_back.jpg`** — Back-facing over-the-shoulder mid-grooming pose.
